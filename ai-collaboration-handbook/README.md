让 AI 帮助人增强认知能力：更有效地获取信息、学习、阅读、思考、科研和组织知识，同时保留提出问题、核验证据和作出判断的责任。

## 使用原则

1. 先确定阅读要支持什么任务，再决定投入多少注意力。
2. 让 AI 建立可返回原文的信息地图；关键证据、参数和限定条件要回看原文。
3. 区分原作者的说法、已核对的事实、研究发现和本手册的实践建议。
4. 对需要掌握的内容，加入独立复述、推导、练习和迁移；流畅的解释不能代替这些表现。

不必对所有材料执行全部步骤。低风险、仅用于发现线索的阅读可简化；用于重要判断、教学或科研的结论应提高核验深度。

## 内容与维护

`docs/` 保存主题正文，`templates/` 保存可复用工具，`sources/` 保存原始材料与引用登记。跨主题共用的来源核验方法集中在 `docs/shared/`，主题文档通过相对链接引用。

当前采用纯 Markdown 和 Git，不需要安装依赖。用任意支持 UTF-8 的文本编辑器或 Markdown 阅读器即可使用；全文检索可用编辑器搜索或 `rg`。文件名使用稳定英文，主要正文使用中文。

**云端 `ChatGPT_CodeX` 仓库是长期主要工作区**；本手册位于独立子目录 `ai-collaboration-handbook/`，Windows 用于按需获取整个仓库的副本。沿用仓库根目录的 Git，不创建嵌套仓库。正式知识、进度、规范和关键决策保存在项目文件中。

开始新任务时读取 [维护规范](AGENTS.md)、[项目状态](PROJECT_STATUS.md)和[总目录](SUMMARY.md)。重要修改完成后先审查差异，再由用户明确授权提交；不自动提交、推送或发布。

日常新增材料可直接使用：

> 请按项目规范收录以下材料，判断应更新已有章节还是新增主题；保留来源，标出冲突和待核实内容，同步索引、状态与更新日志。完成后展示差异，暂不提交。

未来方向见 [项目状态](PROJECT_STATUS.md#未来方向)。这些是规划，不是已完成内容。网站化与自动化只在实际规模需要时引入。
