# AI 辅助阅读指南

**成熟度：首版已整理，研究与核验范围按条目标注。** 主要素材为 [S001](../../sources/S001-reading-discussion.md)；新增案例步骤、检查表与工具属于编辑扩展。证据边界见 [理论与证据](06-theory-and-evidence.md)。

阅读慢、AI 摘要快，却可能省略你真正需要的条件与推导。解决这个矛盾，不能只比较谁更快，而要先决定：这篇材料要支持什么任务，哪些错误会改变判断，哪些能力必须通过自己练习形成。

本指南把 AI 用作导航员、解释器与审查助手，把阅读目的、证据核验和最终判断交还给读者。这是可调整的分工：不要求所有文章精读，也不要求所有重要知识先经过 AI。

## 两条使用路径

**现在就读一篇文章：** 打开决策工具，填写一个阅读目标，按六步流程选用[模板](../../SUMMARY.md#实践工具)，用阅读笔记保存结果。

**系统建立习惯：** 顺序阅读前六章，再独立完成一个案例；一段时间后回看哪些 AI 帮助节省了查找，哪些理解仍需自己的练习。不要用摘要数量代替学习质量。

## 如何判断一次阅读是否足够

足够是相对于任务而言的：发现线索可能只需知道是否值得继续；评价论证需要能追溯关键证据；掌握模型还需要能说明假设并完成推导或应用。一次复述不是永久掌握的证明，查漏也不是绝对完整性的保证。

后续补充真实文章与论文时，按[维护规范](../../AGENTS.md)记录来源及改动，不把新例子无限追加到正文末尾。
