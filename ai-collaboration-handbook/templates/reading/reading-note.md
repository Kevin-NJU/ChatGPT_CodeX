# 阅读笔记模板

复制正文到自己的笔记位置，不在本模板中累积文章记录。笔记若纳入手册，应先确定来源与主题归属。

```markdown
# 【材料标题】

- 作者／来源／链接或文件：
- 发布日期、版本、阅读日期：
- 阅读目的、已有知识、选择层级：
- 预计时间／实际时间（可选）：
- 材料范围：正文／图表／公式／附件／代码各自是否可读：

## 预览与自己的问题

【先写自己的初步地图，不照抄 AI】

## 论证与证据

| 主张与类型 | 证据及位置 | 条件与限制 | 核验状态 |
| --- | --- | --- | --- |
| 作者说法／研究发现／我的判断／AI推断 | | | |

## 我的理解与独立重建

【问题—方法—证据—结论；先关闭回答和原文后写，再对照纠错】

## 查漏与纠错

| 原理解或遗漏 | 原文依据 | 修订与对判断的影响 |
| --- | --- | --- |
| | | |

## 应用或迁移检查

- 完成的推导、练习、最小实现或复现：
- 实际执行范围与结果；未执行的内容：
- 改变了什么条件，哪些结论需要重检：

## 未决问题与下一步

- 不可访问材料及其影响：
- 未核实主张、冲突和需要补的前置知识：
- 停止／回读／查来源／继续练习：
- 可关联的既有知识与笔记：
```

使用原则：[来源与核验](../../docs/shared/source-verification.md)、[阅读结束检查](../../docs/reading/08-decision-guide.md)。
