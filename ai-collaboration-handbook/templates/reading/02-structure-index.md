# 文章结构提取提示词

适用：建立可回到原文的信息地图。基于 S001 原提示词扩展，对应[流程第三步](../../docs/reading/04-collaborative-workflow.md#step-3)。

```text
请作为阅读导航助手建立索引，不要只生成一篇缩短的文章。

阅读目的：【填写】
原文及版本：【粘贴／文件】
已有预览与疑问：【填写】

先列出你实际可读取的正文、图片、表格、公式和附件；无法读取的单独标记。
按原文顺序输出表格：
章节或段落位置｜本部分的问题／主张｜支持证据与数据｜假设与限定条件｜作者承认的不足或疑问｜与我的目的的关系。

要求：
- 区分原作者陈述、作者解释、你的推断、外部补充；原作者陈述不等于已核实事实。
- 对关键项给真实页码、图表号或标题与段落起句，说明页码体系；无法确定则标明，不猜测。
- 标出普通摘要容易丢掉但可能改变理解的条件、反例和推理环节。
- 列出建议精读的位置和理由，而不是只按篇幅分配重点。
- 若分批处理，记录本批范围与未处理范围；不得把局部输出称为全文覆盖。
- 不补造缺失数据、引用或不可见图像内容。
```

使用后：人工抽查关键位置，优先回读证据与限定条件。长文分批索引后仍需对照全文章节检查遗漏。
