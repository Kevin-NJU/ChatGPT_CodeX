# Progress & Adaptation

[sessions.csv](sessions.csv) 是 Session 索引，[reading.csv](reading.csv) 保存可复算阅读原始量；当前均只有表头。自述能力保存在 [PROFILE](../PROFILE.md)，当前恢复位置保存在 [STATE](../STATE.md)，完整对话保存在[学习日记录](../sessions/README.md)。

## 统计口径

- 实际学习日 = Session 表 `learning_activity=yes` 的不同日期数；同一天多次只算一天，初始化不算。课程 completed 与实际参与是两个不同变量。
- 频率报告同时给出实际学习日数与覆盖的日历窗口；实际投入仅汇总有来源的时间，并列出缺失数量，不拿预算补齐。
- WPM 和理解准确率按 [DATA_MODEL](../DATA_MODEL.md)计算，缺失计时留未知。阅读长度、难度、任务模式、工具条件不同不可直接算提升幅度。
- 语法错误只在相同定义与可比任务暴露下比较。错误少可能是写得更少/题更简单，不直接称进步；样本足够时提供独立任务数和分母。
- 词汇层级与主动使用看跨日、新语境的证据，不报告“出现过的单词都已掌握”。

## 周期回顾与计划版本

首次约 7 个实际学习日后用[周期模板](../templates/periodic-review.md)生成 `periodic-review-000001.md`（PRG-000001）。之后以最近回顾覆盖的最后学习日期为界，累计约 7 个新的实际学习日；同日追加 Session 不额外计日。跨日很久可提前回顾，写清触发理由与实际样本。

首次诊断完成后才用[计划模板](../templates/learning-plan.md)创建 `plan-000001.md`；重大调整递增版本并链接替代关系，STATE 指向当前版本。模板目前没有被实例化为真实计划、进展报告或成绩。

周期回顾包含学习频率、完成内容、可比指标、典型错误/词汇变化、策略效果、数据缺口和下一步调整。没有数据就说尚不能判断，不编造进步百分比或稳定提升趋势。
