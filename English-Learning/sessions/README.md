# Detailed Learning History

学习活动发生后才按 `YYYY/MM/YYYY-MM-DD.md` 创建文件；当前没有真实学习日，故无日期目录。使用[学习日模板](../templates/session.md)，路径、ID 和时区见 [DATA_MODEL](../DATA_MODEL.md)。

同日多轮学习追加不同 Session；Session 内追加题目、原答、反馈、自改与检查点。跨日继续旧题在新日期记录中链接旧题，不能覆盖旧文件。每个原答有独立 attempt 锚点，保持文字、错误和修改顺序；原答含 Markdown 围栏时选择比原文更长的围栏包裹，不能为排版而更改原答。

每回合记录当前可见互动，题目与教师完整反馈一并保存，来源不可见的内容标明缺口；没有声称自动读取历史聊天或语音的能力。保存采用先历史、再 CSV、最后 STATE 的顺序，见[学习协议](../LEARNING_PROTOCOL.md)。

详细对话可能包含个人信息，默认只在本地维护。公开仓库上传前须另行确认范围与脱敏方式；不能把“已保存到工作区”说成“已同步到 GitHub”。
