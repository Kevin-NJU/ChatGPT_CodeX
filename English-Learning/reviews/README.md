# Spaced Review

[queue.csv](queue.csv) 保存当前排程，[events.csv](events.csv) 追加真实复习事件；初始化均无数据。复习目标可为词汇、错误知识点，或已有任务的迁移检索。字段见 [DATA_MODEL](../DATA_MODEL.md)。

Day 1 后的入口：[Day 2 前复习清单](day1-before-day2.md)。已收录用户问过的词/短语、时态标签、主要错误、拼写提醒及可接受表达；目前是待复习资料，不是完成记录。

## 到期选择与初次排程

默认对值得追踪的新项安排实际学习日的次日复习（间隔 1 个日历天），时间不足可协商不同日期并记录理由。当天复习优先 `status=scheduled`、`due_on <= today`，再结合最近失败、遗忘风险与当前目标挑选；没有实际练习不记录事件。

同一目标仅一条非 retired 队列项。已有项更新而非重复创建。Listening / Speaking 未启用时不得排入课程或复习；若导入队列含这些项目，应 paused 并说明来源与启用门槛。

## 项目内初始间隔策略

采用可调整的轻量启发式，**不是经过个体校准的遗忘预测或官方算法**。默认阶梯为 `1, 3, 7, 14, 30, 60` 日，超过后可保持 60 日或按目标协商，调整写入日志。

| outcome | 真实表现 | 默认结算 |
| --- | --- | --- |
| again | 无法独立检索、关键错误或看示范后才完成 | 新 interval=1，success_streak=0 |
| hard | 部分检索、明显费力或经提示完成 | 新 interval=max(1, floor(旧 interval/2))，success_streak=0 |
| good | 独立正确，能说明/应用于要求的语境 | 升至阶梯中大于旧间隔的下一档，上限 60；streak+1 |
| easy | 独立、准确且调用顺畅，并有适用的迁移证据 | 可升至更大的第二档，上限 60；streak+1，不直接判定掌握 |
| not_completed | 任务取消、中断，尚未完成检索 | 不结算；保留队列日期、间隔和 streak |

有提示/范文/外部帮助时 assistance 不为 none，不记为 good/easy。结合真实结果选择 again 或 hard，不能以事后抄对当成功。下一 due_on = **实际 reviewed_on + 新 interval**；从实际复习日重算，不从错过的原到期日累积“补考”。

追加实际尝试事件，记录旧值 → 新值和依据，再更新 queue 的日期、间隔、连续成功和证据。同一复习结果只计一次。队列 last_reviewed / last_outcome 应匹配最新已结算事件；not_completed 事件不改变它们。若更正既有结算，先在日志保留同一 RVE ID 的原值、新值和理由，再更新该索引行并重核受影响的当前队列；不改历史实际发生日期，不把评分更正计为一次新复习。

## 暂停与预算不足

没有到期复习不制造任务。逾期不等于失败，未执行的不写 outcome。暂停项保留记录和日期；恢复时按最近真实检索结果重排，不假设间隔内一直记得。若积压严重，分批做高价值检索并缩减新内容，不以清空队列为学习目标。

日期只是待执行安排，没有后台通知或自动教学服务。课程结束核对实际完成的事件和未完成项，再保存 [STATE](../STATE.md)。
