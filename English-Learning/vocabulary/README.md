# Vocabulary Tracking

[items.csv](items.csv) 保存有真实练习证据的条目；Day 1 已记录 address。用户问过、已解释但尚未独立检索的 recap、batch、vague、prose、fits、wrap up 和时态标签集中在 [Day 2 前复习清单](../reviews/day1-before-day2.md)，已通过原任务加入队列；不是遗漏，也不填造掌握层级或最近练习日。完整字段见 [DATA_MODEL](../DATA_MODEL.md)。追踪单位是词/词组的具体义项和词性，不是单个词形的永久“会/不会”。

| 层级 | 本次任务能支持的描述 | 需要的证据 |
| --- | --- | --- |
| unassessed | 尚未评估使用层级 | 不把出现过词形当测评 |
| L0 | 不认识该词/义项 | 用户明确报告或任务证据；不能由跳过直接推断 |
| L1 | 认识词形，但准确语境义、搭配或用法不清楚 | 实际解释/选择/使用暴露局限 |
| L2 | 能理解当前语境，但尚不能独立主动使用 | 配对理解与产出任务；没有产出测试则主动能力未知 |
| L3 | 能准确使用，但调用不够流畅 | 独立表达正确，加可确认的犹豫/时间或用户反馈 |
| L4 | 在已观察语境中准确、自然且较熟练地使用 | 多次、跨日、新语境独立运用及效率证据；不代表所有义项掌握 |

若首答准确且没有可靠流畅度证据，描述“已观察准确使用，流畅度待验证”，暂不强升 L4；层级解释保存在日志，必要时保持原层级而新增证据说明。单次好表现不自动设 `stable`，也不因一次忘记就抹去所有历史。

记录词性、语境义、搭配、例句、真实原错、层级及练习日期。需要复习时关联 REV ID，**下次复习日期只从[队列](../reviews/queue.csv)读取**。层级与状态变化写入当日学习记录并链接原答，形成可追溯历史；不以“背完多少词”替代运用证据。
