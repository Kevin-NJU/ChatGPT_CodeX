# Materials & Provenance

[registry.csv](registry.csv) 当前只有表头。实际出题时再按[素材模板](../templates/material.md)创建材料并分配 MAT ID，不提前放置答案或假题作答记录。

优先自编通用语境材料，注明 `tutor_authored`，不能冒充 CET 真题或官方分级语料；使用用户提供或外部材料时记录定位、实际访问范围、日期与使用边界。只保留有权存储的正文或必要摘录，不把外链或摘要写成已经读过全文。

用于计时阅读的材料必须保存当次精确正文、词数和计词规则，文章修改另建 MAT ID；题目、标题和来源不计入词数。答题前材料文件不含答案键。讲评后反馈仍保存在对应 attempt，不与原材料混写。

专业材料在基础训练需要且学习者目标支持时逐步引入，当前不将 CMOS、MOSFET、SOT、MTJ 等术语设为默认课程。未来 Voice/其他平台内容只能导入用户提供的文字或反馈，标记转写/节选与不可访问部分。
