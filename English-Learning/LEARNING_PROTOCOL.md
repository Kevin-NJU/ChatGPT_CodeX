# Learning Protocol

本协议把教学、分析与文件维护串成可恢复的循环。字段与统计定义见 [DATA_MODEL](DATA_MODEL.md)，诊断题型和评分见[首次诊断方案](assessments/initial-assessment.md)。

## A. 开始学习日与课程安排

1. 按 [AGENTS](AGENTS.md) 恢复上下文，检查 `STATE.md`、当前计划、未完成题与到期队列。缺失文件或证据冲突先处理，不能从聊天记忆推测。
2. 问 **How much time do you have for English today?**。同一学习日已有预算不重复问；可以确认剩余时间。学习日使用 `Asia/Shanghai`，预算不是实际耗时。
3. 查看 `reviews/queue.csv` 的 `scheduled` 且 `due_on <= today` 条目，优先近期错误、上次失败及逾期项；预算不够可选择关键几项，其余保留逾期，不标为失败或完成。诊断初期空队列无需复习；为保护独立基线，先测再教。
4. 展示五项简短计划：**Today’s Goal / Review Tasks / Main Practice / Estimated Time / Expected Outcome**，说明 Accuracy 或 Fluency 模式及预计反馈点；允许用户调整。
5. 15 分钟可只完成小段诊断、关键复习或一个输出任务；30 分钟可组合复习与主练习；60–90 分钟可加入更深入迁移和休息。按能力证据决定内容，不把时长变成固定题量。

## B. 互动与反馈

每次只呈现一个任务或少量短子题。出题即保存题目、材料、任务 ID、模式、允许工具、评分维度与计时边界；**不保存或展示该题答案键**。用户提交后先保存逐字原答及自报耗时，再评分和反馈。若答案不完整，只请求必要补充，不凭空补齐句子或分数。

诊断首答默认独立、不查词；用户使用提示或外部工具时如实标注而不惩罚性猜分。先完成相关独立小批次，再提供教学反馈。反馈后的重答和补充迁移单列 `assisted` / `post_feedback`，不得回填为首答成绩。

Accuracy Mode 可逐步解释、引导一次自改；Fluency Mode 约定时间/完成边界，不中断逐句纠正，先输出再选 1–2 个高影响问题处理。默认同题最多一次自改、再一次新语境迁移；如仍困难则示范、安排复习，用户愿意时才延长。

对错误按需要提供原答、修正版、原因、自然替代表达、常见误区与后续练习。原因是分析假设，尤其“粗心”“不会规则”“中文迁移”等不能无证据确定。能接受的多种表达应说明语境与风格差异。

## C. 每回合保存与暂停恢复

执行保存顺序：**详细记录 → 证据支持的 CSV 更新 → STATE 检查点**。

- 出题、收到原答、反馈、自改、复习、暂停和结束都是保存点。详细记录用稳定 HTML 锚点；索引和浓缩结论引用对应 attempt，不引用模糊的“上节课”。
- 同一天追加到已有日期文件的新 Session；同一 Session 追加新任务/attempt。跨日恢复时建立新日期文件，链接原题并分配新的 Session；保留原题 ID，只引用旧题锚点，不在新文件重建同一题目锚点；新增 attempt ID 含新 Session 前缀，避免跨日重复 ID。
- 日志已存在时先读末尾，检查 ID 与最后检查点，再追加；失败时不要重复创建同一个事件。若保存工具失败，明确说明尚未落盘的范围并在当前可见上下文中保留待写内容，不宣称已保存。
- 暂停写下实际完成内容、未完成题和具体步骤、最后 attempt、已暴露提示/答案、已用时间（如可确认）、待同步索引及恢复入口。暂停状态不是学习失败，也不是已完成。
- 恢复先回看原题及已有回答，确认是否仍是独立测量；已经见过答案的题改为练习或换一题验证。用户不必重新回答已经保存的内容。

不能读取遗失会话或 Voice 录音；用户提供的回忆只能标为回忆/导入，不能伪装逐字原始记录。无记录的过去活动不计入统计。

## D. 两天诊断与计划门槛

初始诊断以两个学习日为默认：Day 1 词汇、语法、阅读；Day 2 写作、翻译和少量综合补测。两个学习日不必连续，Day 2 日期须晚于 Day 1 完成日。单日不足可分段，跨日需如实延长，不能为了声称“两天完成”压缩或虚构覆盖。Day 1 未完成时先继续 Day 1。

每个模块记录已测 / 部分测 / 未测、样本、首答、提示、评分依据和缺口。两阶段规定的实际任务完成后才能生成报告；如果用户选择结束但有缺项，报告明确为 `partial`，不解锁声称完整诊断的详细个人计划，应先协商补测或明确缩小计划证据范围。

完成后用[报告模板](templates/assessment-report.md)生成 `assessments/initial-report.md`：汇总强弱项、重复错误、词汇识别/调用差距、阅读速度和理解、准确性/流畅度、优先级与局限。随后用[学习计划模板](templates/learning-plan.md)生成首个计划并更新 `PROFILE.md`、`ROADMAP.md`、`STATE.md`。分数无法给出时标定性判断和证据，不能补估总体等级。

## E. 复习、结束与自适应

复习按 [reviews 规则](reviews/README.md)执行。检索优先于重读答案；先尝试再看反馈；间隔从实际复习日计算。到期日期不等于系统已经发出通知，错过一天不自动重置所有进度。

结束按已完成事实总结今天内容、可支持的掌握变化、关键错误、需复习项和下次重点。表述“本次能独立使用”而非没有多次证据的“完全掌握”。确认用户结束后更新 Session 状态；未知实际时长留空。

每约 7 个实际学习日用[周期模板](templates/periodic-review.md)回顾频率、完成内容、阅读可比指标、语法错误、词汇主动使用与策略效果；证据不足不生成增长率。长期中断可先做更短恢复回顾，保留原计数依据。

持续错误 → 检验原因、回到基础或换呈现方式；独立且跨日成功 → 提高语境变化、延长复习间隔；时间减少 → 缩小当日范围、保留未完成项。策略变更写明证据和复查条件，重大计划变更保留旧版本。

## F. 长期模块扩展

在六级后与学习者确认真实用途，再逐渐引入学术阅读、专业表达、学术写作和日常语料。不得仅因日期到来自动切换全部内容。Listening / Speaking 在用户明确开启前不测、不教、不排复习；文本任务不能声称验证了口语或听力。未来 Voice 数据只能导入用户提供的转写/反馈，说明来源、完整性及评估边界。
