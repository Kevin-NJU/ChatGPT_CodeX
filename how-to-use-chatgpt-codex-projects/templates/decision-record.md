# 决策记录模板

用途：记录影响未来的选择，而非每次小编辑。复制下面条目到项目决策文件。

```markdown
## D[编号]：[决定主题]

- 日期：[YYYY-MM-DD]；状态：[提议/已采纳/被 Dxxx 替代]。
- 背景：[问题及约束]。
- 备选：[至少说明有意义的替代方案]。
- 决定：[明确选择]。
- 理由：[为何适合当前需求]。
- 影响：[路径/流程/成本/迁移影响]。
- 复查条件：[何时应重评]。
- 依据：[用户要求、来源、任务记录或实际证据]。
```

旧决定被替代时保留记录和去向，不静默改成仿佛一开始就这样。示例见 [本库决定](../management/DECISIONS.md)。
