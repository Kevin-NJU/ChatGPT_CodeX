# 最小 AGENTS.md 模板

适用：为另一个项目设计 Codex 长期约定。先替换路径和检查方法，不直接复制本指南全部管理文件。发现规则见 [指令章](../docs/05-instructions-prompts.md)。

```markdown
# [项目名] 工作约定

范围：[项目目录]。用户当前明确指令优先；遵循系统、开发者指令和实际权限。

## 开始

检查 Git 状态及适用上层规则；读 [状态入口]，按任务查相关决定与正文。
明确目标、允许路径与验收；保留用户已有工作，多阶段给简短计划。
沿用现有检出，云任务已隔离时不默认创建 worktree 或嵌套仓库。

## 执行

只改任务范围；优先维护已有内容，必要时交叉链接。
功能事实有来源与日期；不确定处标明，不能编造执行结果。
秘密不进文件或输出；专题流程见 [专题指南路径]。

## 完成

执行 [本项目真实且相关的检查方式]，审查新增文件与差异。
每条独立用户任务追加 [任务日志路径]：时间、目标、操作、文件、结果、验证证据、问题、未决项、下一步。
检查状态是否需更新；实质变化才写变更记录，长期决定才记决策。
报告目标、成果、文件、验证、限制和下一步；Git 操作只在本次授权范围执行，不默认合并、强推或部署。
```

若项目选择不强制逐任务日志，可改成与目标相称的机制；不能把本项目自定义规则描述为 Codex 的普遍产品要求。
