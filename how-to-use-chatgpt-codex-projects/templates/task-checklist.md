# 可复用任务检查清单

用途：适合跨阶段任务；简单修改只选相关项。方括号可勾选，不能把未执行项目标为通过。

## 开始前

- [ ] 目标、输入、允许修改路径与验收明确。
- [ ] 目标仓库、分支、工作区和已有改动已核对。
- [ ] 适用规范、当前状态与相关决定已读取。
- [ ] 资料访问、保存许可、权限与必要凭据的状态明确。

## 执行中

- [ ] 在既有章节中定位新材料，重复和冲突已处理或标明。
- [ ] 官方事实、实测、建议、本地约定与待核验内容分开。
- [ ] 文件/命令修改没有超出授权范围。
- [ ] 失败有诊断，不反复执行不变的失败命令。

## 结束前

- [ ] 新增文件逐一审查；目录、相对链接及锚点可用。
- [ ] 相关功能或文档检查完成，证据属于当前结果。
- [ ] 来源日期、访问范围、平台与套餐条件没有缺失。
- [ ] 无占位空章、未闭合围栏、冲突标记和意外敏感信息。
- [ ] 任务日志已追加；STATUS 等按职责判断是否更新。
- [ ] 暂存和差异只包含授权路径，提交/推送/PR 分开核实。
- [ ] 最终报告写明未完成、未验证、限制与下一步。

本库首版实际检查记录见 [VALIDATION](../management/VALIDATION.md)。
