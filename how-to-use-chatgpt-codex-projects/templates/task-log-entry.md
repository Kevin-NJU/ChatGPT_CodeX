# 任务日志条目模板

用途：每条独立用户任务完成后追加一次；不是每条命令一条。相同任务的补充结果更新原条目并注明更新时间，避免假装成额外用户任务。

```markdown
## T[编号]：[任务标题]

- 时间：[YYYY-MM-DD HH:mm:ss +08:00，Asia/Shanghai]；补充更新时间：[如有]。
- 任务目标：[用户要求与范围]。
- 主要操作：[实际执行，计划与完成分开]。
- 文件：[新增/修改/删除清单或可点击的完整变更索引]。
- 执行结果：[已完成、部分完成、失败；Git 操作分别写]。
- 验证与证据：[命令/对象/结果/证据位置，未运行与失败明确写]。
- 问题及处理：[真实阻塞或修正；没有则写无]。
- 未解决问题：[影响与剩余前提]。
- 后续建议：[下一件可执行任务]。
```

仅调查时也记录结果和未改正文的原因。全只读任务的例外见 [AGENTS](../AGENTS.md)。不要为了把该条记录自己的提交号写进去无限追加提交；当前提交从 Git 查询即可。
