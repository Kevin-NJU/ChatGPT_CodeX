# STATUS 模板

用途：给新会话一个当前快照；不保存全部历史。复制到目标项目后替换占位符。

```markdown
# 当前状态

更新：[YYYY-MM-DD HH:mm +08:00]。目标：[一句话]。
阶段：[进行中/暂停/已归档]；正式资料入口：[路径]。

## 已完成

[成果及对应文件；验证证据用链接，不写计划成功。]

## 当前工作

[下一件明确任务、完成条件、相关决定/任务 ID。]

## 阻塞与未知

[问题、影响、缺什么前提；没有则写无已知阻塞。]

## 接手

[最小阅读顺序、必要环境步骤、当前 Git 状态的查询方法。]
```

提交号不能自引用当前提交；动态 Git 状态先查询，静态快照注明记录时间。职责见 [架构](../docs/03-project-architecture.md)。
