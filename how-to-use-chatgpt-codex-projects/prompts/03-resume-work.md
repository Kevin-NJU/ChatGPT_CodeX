# 跨日期继续工作提示词

## 适用场景

新聊天、隔日或换设备后接着做。

## 使用前提

实际检出可访问；若只有旧摘要，应明确缺失项。

## 可复制提示词

```text
请接手 [仓库与项目目录]，继续 [本次目标]。
先查实际工作目录、远程、分支、HEAD、git status 和适用 AGENTS.md；保留未提交改动，不自动 reset、clean 或覆盖文件。
读当前 STATUS、与目标相关的 DECISIONS 和最近必要任务记录，再按索引读取相关正文。不要机械载入全部历史，也不要把我的摘要 [可选摘要] 当成正式事实。
核对文件状态与 Git 记录是否一致，区分仅磁盘、已提交、已推送、会话临时信息和推断。如需同步远程，先确认本地变化及授权，使用不会丢失工作的步骤。
简述已确认状态、下一步和未知项，再在 [允许路径] 完成本次工作及相关检查；运行中的服务按必要步骤重新验证。
按项目日志约定追加本次任务事实，并报告结果与未完成项。Git 授权为 [授权范围]，不因旧任务曾允许推送而沿用授权。
```

## 替换变量

仓库与项目目录、本次目标、可选摘要、允许路径、授权范围。

## 预期输出

当前状态复核、恢复后的实际产物、检查证据与下一步。

## 注意事项

新建任务不保证继承旧任务未提交文件；材料不在时报告缺失，不能凭记忆重建为确定事实。

相关规则见 [指令设计](../docs/05-instructions-prompts.md) 和 [本库维护](../docs/09-maintaining-this-guide.md)。
