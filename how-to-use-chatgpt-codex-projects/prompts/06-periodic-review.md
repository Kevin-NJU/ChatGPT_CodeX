# 项目定期检查提示词

## 适用场景

检查过期资料、状态漂移、重复信息和知识债务。

## 使用前提

指定检查范围、时间预算和是否允许直接修正。

## 可复制提示词

```text
请检查 [项目目录]，重点为 [重点主题]，时间/工作范围为 [检查边界]。
先读适用规范、STATUS、ROADMAP、来源登记，再按风险选择页面。区分产品易变事实、稳定实践与本项目约定。
核验来源是否仍可访问、结论是否仍受支持，比较当前官方正文与旧记录；HTTP 成功不等于结论有效。无账号界面权限的行为标记未实测。
检查索引、坏链接/锚点、重复和矛盾、状态与实际文件不一致、长期无归属待办、过长指令和日志。
允许操作：[只调查并记日志/在指定路径修正已确认问题]。不为了整洁删除历史或重构全库。新研究任务写有完成条件的候选，不冒充解决。
给出问题、证据、影响、最小处理和优先级，记录本次任务及未检查范围。Git 授权：[授权范围]。
```

## 替换变量

项目目录、重点主题、检查边界、允许操作、授权范围。

## 预期输出

有证据的问题清单、已修正与未修正的明确区分。

## 注意事项

该提示词不会自动建立定时任务；若要定时，另确认工具、频率、权限与成本。

相关规则见 [指令设计](../docs/05-instructions-prompts.md) 和 [本库维护](../docs/09-maintaining-this-guide.md)。
