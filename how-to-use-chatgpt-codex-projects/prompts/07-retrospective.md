# 项目复盘提示词

## 适用场景

阶段完成或反复失败后提炼可复用经验。

## 使用前提

有真实操作记录、差异或验证证据，而非仅有计划。

## 可复制提示词

```text
请基于 [任务日志/提交/检查证据] 复盘 [阶段或任务]。
先重建目标、约束和实际发生的过程，区分计划、观察、推断和用户已确认决定。不从单次失败编造根因。
分析哪些做法减少了恢复成本，哪些造成重复、范围漂移或验证缺口；每项都给证据、影响、可能原因和验证改进的方法。
将建议归属到一个主要位置：任务特定说明、已有章节、长期 AGENTS 规则、现有模板或无需流程改变。避免因一次小问题引入复杂系统。
本次只允许 [复盘允许路径与操作]，未授权不把建议直接实施为全库改造。按项目规范记录本次复盘任务，未改正文时说明原因。
输出有效实践、问题与证据、优先改进、待验证假设和下一步。
```

## 替换变量

任务日志/提交/检查证据、阶段或任务、复盘允许路径与操作。

## 预期输出

可追溯复盘和少量能验证效果的改进。

## 注意事项

模型的推理过程不需要也不应作为日志；保留可观察执行事实。

相关规则见 [指令设计](../docs/05-instructions-prompts.md) 和 [本库维护](../docs/09-maintaining-this-guide.md)。
