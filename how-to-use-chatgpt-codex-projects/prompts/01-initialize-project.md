# 项目初始化提示词

## 适用场景

首次建立一个长期项目，而非每次恢复时重建。

## 使用前提

已确定可访问的目标仓库/目录；对现存文件先检查。

## 可复制提示词

```text
请在 [仓库/工作目录] 中初始化 [项目名称]，目标是 [可观察成果]，主要读者是 [读者]。
先确认远程、当前分支、适用 AGENTS.md、已有同主题内容和未提交差异。只允许创建或修改 [允许路径]，保留现存工作；不新建嵌套仓库。
根据 [资料位置] 分析目标、非目标、输入、生命周期及权限。给出比例适当的简短架构，然后建立可使用的入口、必要状态与基础内容；不要创建空目录或给小任务套完整工程框架。
产品功能先查官方资料，记录日期和范围，不能确认的列待核验。说明哪些是产品能力，哪些是自定义约定。
完成文件/链接/内容与范围检查，按该项目规范记录本次任务；没有既有日志约定时选择最小有用记录机制。报告实际成果、证据和下一步。
Git 授权：[仅本地/允许提交/允许推送指定分支及 PR]；未授权不合并、部署或发布。
```

## 替换变量

仓库/工作目录、项目名称、可观察成果、读者、允许路径、资料位置、Git 授权。

## 预期输出

目标边界、最小架构、可用首版、验证和任务摘要。

## 注意事项

初始化不表示 ChatGPT 设置已创建；Project Instructions 需在有权限的产品入口应用。

相关规则见 [指令设计](../docs/05-instructions-prompts.md) 和 [本库维护](../docs/09-maintaining-this-guide.md)。
