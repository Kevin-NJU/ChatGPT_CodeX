# 知识库扩展提示词

## 适用场景

新增问题、资料或经验，需要整合而非不断追加文章。

## 使用前提

已有目录索引和来源；资料的保存/公开权限明确。

## 可复制提示词

```text
请将 [新问题或材料] 整合进 [知识库目录]。
先查索引、状态和相关章节，用同义词搜索现有论点，判断是原章更新、交叉链接、独立主题还是仅进入待研究清单，并解释归属。
优先维护原章；确需新章时写实质内容并纳入入口。原始材料的观点、官方事实、实践建议和不确定推断分开，不静默改写归档来源。
新功能查官方出处，记录链接、核验日期、访问层级和适用条件；冲突先比较定义、套餐、平台和版本，不能确认则标注争议。
仅修改 [允许路径]，修复相关目录与入链，检查重复、矛盾、失效引用及内容边界。
按任务单位追加日志，并只更新确有变化的状态/来源/变更/决策；最后列出新内容去向、验证和未决问题。Git 授权：[授权范围]。
```

## 替换变量

新问题或材料、知识库目录、允许路径、授权范围。

## 预期输出

可发现的新知识、明确来源、旧内容去重及链接检查。

## 注意事项

不要将每份材料的标题直接变成新文件；不要复制无权公开的全文。

相关规则见 [指令设计](../docs/05-instructions-prompts.md) 和 [本库维护](../docs/09-maintaining-this-guide.md)。
