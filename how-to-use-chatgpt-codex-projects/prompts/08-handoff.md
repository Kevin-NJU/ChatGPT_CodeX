# 项目迁移与交接提示词

## 适用场景

交给新会话、协作者或另一设备。

## 使用前提

明确接收者权限、可迁移材料与真实检出状态。

## 可复制提示词

```text
请为 [接收者/目标环境] 准备 [项目目录] 的交接，范围为 [交接范围]。
确认实际仓库、工作目录、分支、HEAD、未提交/未跟踪/忽略文件；检查正式 STATUS 和关键决定与实际产物是否一致。
给出最小阅读路径、已完成成果、最后检查及其证据、已知问题、下一步和不可越过的权限边界。
分别列出已在远程的提交、仅本地内容和需要单独迁移的非秘密文件。进程、凭据和插件授权不能假定随 Git 运输；给安全的重新初始化与就绪检查方法，不复制秘密值。
只允许修改 [允许路径]，保留原环境和现有工作，不直接删除或覆盖；需要变更共享范围时先明确接收者和资料。
按任务单位记日志，并给接收者一段可以直接复制的恢复指令。Git 授权：[授权范围]；未实际在目标环境验证的内容明确标记。
```

## 替换变量

接收者/目标环境、项目目录、交接范围、允许路径、授权范围。

## 预期输出

非秘密交接清单、最小恢复指令与未验证迁移项。

## 注意事项

复制目录不等于迁移认证；正式跨设备验证需要在目标环境实际运行。

相关规则见 [指令设计](../docs/05-instructions-prompts.md) 和 [本库维护](../docs/09-maintaining-this-guide.md)。
