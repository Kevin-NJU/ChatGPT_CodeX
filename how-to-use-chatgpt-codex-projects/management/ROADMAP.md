# 路线图与研究候选

此处只记录未来工作，不代表已实现功能。不承诺未确认日期；优先级随实际问题调整。

| ID / 优先级 | 研究或实践 | 完成条件 | 前提与边界 |
| --- | --- | --- | --- |
| R01 / 高 | 本库真实跨日恢复 | 新任务按状态接手、更新原章、追加日志，能追溯版本与下一步 | 用户下一次独立任务；不为演练制造额外用户请求 |
| R02 / 高 | 项目记忆设置与共享边界实测 | 在可丢弃、无秘密项目中记录套餐、客户端、设置、等待时间和观察，比较 O1 | 可访问账号与相应授权；未读到/未引用不能单独证明隔离失败 |
| R03 / 高 | Work/Codex 跨设备与文件交接 | 分清 Chat/Work/Codex 历史、云/本地文件，记录实际可继续对象 | 用户设备和实际权限；不假定自动镜像仓库 |
| R04 / 高时效 | GPTs 迁移与 plugins 替代方案 | 按最新官方通知更新时间/可用性，补充在可用工具上的真实迁移案例 | 不依赖即将退役能力初始化新项目；需要具体账号范围 |
| R05 / 中 | 在一个真实代码仓库应用 SOP | 有实际复现、相关测试、环境记录和可审查分支/PR | 另一个明确授权任务；本项目不修改兄弟工程 |
| R06 / 中 | 并行会话与冲突恢复演练 | 在隔离演练分支保留双方修改、正确整合日志和复验 | 独立授权，不在用户当前工作上制造破坏 |
| R07 / 按需 | 日志归档或轻量结构检查自动化 | 确有增长/重复错误成本，工具可识别已知坏样本，仍保持入口可用 | 当前无必要不创建框架或空归档 |

建议每季度复核产品事实，若公告/界面变化则提前；这是人工维护建议，未创建自动定时任务。评估新增问题时先找现有章节，明确价值与验收后再扩大范围。
